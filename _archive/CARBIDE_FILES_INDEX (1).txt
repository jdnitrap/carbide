CARBIDE_V1.0_BATCH.PY (Version 1.0 - Batch Mode)
══════════════════════════════════════════════════════════════════════════════════

File: carbide_v1.0_batch.py
Lines: 424
Dependencies: torch, matplotlib
Requires: GPU preferred (CPU: ~25 min)

Purpose:
  Original implementation. Batch training → generation → ablation → export.
  No user interaction. Runs start-to-finish automatically.

Workflow:
  1. python3 carbide.py
  2. Trains for 3000 steps (~15 min on CPU)
  3. Generates sample text
  4. Runs ablation (3×1500 steps, ~10 min)
  5. Exports: carbide_loss.png, carbide_loss.csv, carbide_ablation.png, mdbe_table.csv
  6. Done. Exit.

Use When:
  ✓ You want a simple, single run
  ✓ Fire-and-forget training
  ✓ Baseline comparison
  ✓ Quick proof-of-concept

Don't Use When:
  ✗ You want interactive REPL
  ✗ You need to pause/resume
  ✗ You want to load custom datasets
  ✗ You need real-time control

Setup:
  python3 -m venv carbide_env
  source carbide_env/bin/activate
  pip install torch matplotlib
  python3 carbide_v1.0_batch.py

ARCHITECTURE (All Versions)
══════════════════════════════════════════════════════════════════════════════════

All three versions share the same core architecture:

Input:
  Raw UTF-8 text → bytes (0-255)

MDBE (Mechanically Defined Byte Embedding):
  • 256-row learned embedding (64 dims per byte)
  • 6 rule-based constraints per byte:
    - is_alphabetic (A-Z, a-z)
    - is_digit (0-9)
    - is_uppercase (A-Z)
    - is_punctuation (!-/, :-, etc.)
    - is_whitespace (space, tab, newline, CR)
    - utf8_lead (UTF-8 lead byte indicator)
  • Linear projection (64+6 → 64)

SSM Blocks (×n_layers, default=2):
  • Selective Scan state evolution
  • Pre-norm residual connection
  • State dimension: d_state (default=16)

Output Head:
  • Linear(64 → 256) logits
  • Cross-entropy loss on next-byte prediction

Training:
  • Optimizer: AdamW (lr=3e-3)
  • Gradient clipping: 1.0
  • Default: 3000 steps, batch_size=1, seq_len=128

Ablation:
  • Mode A: full (constraints on)
  • Mode B: no_constraints (constraints zeroed)
  • Mode C: plain_embedding (skip projection)

COMMON QUESTIONS
══════════════════════════════════════════════════════════════════════════════════

Q: Which version should I start with?
A: If you have torch: carbide_v2.0_interactive.py
   If you don't: carbide_v1.0_demo.py

Q: Can I use carbide_v1.0_batch.py to load custom text?
A: No. Create train.txt in the same folder, or use carbide_v2.0_interactive.py

Q: Does carbide_v1.0_demo.py generate real output?
A: No, it's simplified/mocked. For real training, use carbide_v1.0_batch.py or 
   carbide_v2.0_interactive.py with torch.

Q: Can I run carbide_v2.0_interactive.py without torch?
A: No, the interactive version requires torch for actual training. Use 
   carbide_v1.0_demo.py for instant feedback without dependencies.

Q: How do I switch between versions?
A: They're independent files. Run whichever you want:
   python3 carbide_v1.0_batch.py
   python3 carbide_v1.0_demo.py
   python3 carbide_v2.0_interactive.py

Q: Do I need to install all three?
A: No. Pick one based on your needs. All three are self-contained.
